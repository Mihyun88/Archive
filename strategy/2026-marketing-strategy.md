# 착한언니복덕방 마케팅 전략 · 자동화 방향 (2026.11)

> 한 줄 정의: **"2014년 겨울부터 신촌 한 자리, 마포·서대문을 가장 깊게 아는 중개사"**
> 정보는 AI가 누구에게나 주지만, **현장·거래 경험·지역 네트워크**는 우리만 줄 수 있어요. 마케팅은 이 차이를 보여주는 일에 집중하고, 나머지는 자동화합니다.

- 블로그 톤: "투자 수익"보다 **"이 집에 살아도 되는지, 이 가격이 맞는지"**

## 3. 왜 '전문성 강화'인가 — AI 시대 중개사의 자리

고객이 AI로 이미 얻는 것: 실거래가, 일반 계약 상식, 정책 요약, 체크리스트
→ 이걸 블로그에 쓰면 **AI와 경쟁**이고, 이길 수 없어요.

**AI가 못 주는 것 = 우리 콘텐츠의 재료**
1. **현장**: 같은 건물이라도 호실·층·향마다 다른 소음·채광·옵션 상태, 실제 관리비, 엘리베이터 대기, 주차
2. **거래 경험**: "12년간 이 건물에서 n건 계약하며 본 것", 집주인·관리단 성향, 협상이 되는 시기
3. **비공개 흐름**: 지금 나올 예정인 매물, 실제 호가와 거래가 차이, 대기 수요
4. **책임**: 계약 리스크를 같이 지는 사람 (특약, 보증보험, 등기 확인)

**콘텐츠 규칙**: 모든 글에 **"착한언니 현장 노트"** 단락을 반드시 넣는다. 이 단락이 없으면 발행하지 않는다.

### 우리만의 자산 만들기: "마포·서대문 건물·단지 백과"
- 오피스텔 건물별, 아파트 단지별로 **같은 틀의 카드**를 하나씩 쌓아요 (호두네 【아파트정보】처럼)
- 틀: 기본 정보(건축물대장) + 실거래·전세(국토부, 자동) + **현장 노트(직접)** + 이런 분께 맞아요 + 법정 표시
- 30개 쌓이면 "신촌·이대 오피스텔 지도" 허브 글로 묶어서 블로그 고정 + 카톡 채널 메뉴에 연결
- 이 백과는 AI가 학습할 수도 없는 **현장 데이터**라 시간이 갈수록 해자가 돼요

## 4. 채널별 역할 — 1인 운영 기준으로 다시 나누기

지금처럼 5개 채널을 각각 따로 만들면 지속이 어려워요. **블로그 1개를 원천으로 만들고 나머지는 변환**합니다.

```
            [원천] 네이버 블로그 글 (주 3편)
                       │  ← 자동: 데이터 표·초안 / 직접: 현장 노트·사진
     ┌────────────┬─────┴───────┬──────────────┐
  인스타 카드      릴스 1편         카톡 채널        플레이스 소식
  (자동 변환)   → 클립·쇼츠 동시   (주 1회 리포트)   (블로그 링크 공유)
     │               │                │
     └───────────────┴──── 모든 CTA ──→ 카톡 채널 상담 ← 고객 명단
```

| 채널 | 역할 | 목표 빈도 | 담당 |
|---|---|---|---|
| **네이버 블로그** | 원천 · 검색 · 전문성 증명 | 주 3편 | 초안 자동 + 현장 직접 |
| **카카오 채널** | **고객 명단 · 상담 · 재방문** (가장 중요한 자산) | 주 1회 메시지 | 자동 초안 → 확인 후 발송 |
| **인스타그램** | 도달 · 신뢰 (아파트 쪽) | 주 7 → **주 4~5**로 축소 | 블로그 글 → 카드 자동 변환 |
| **유튜브 쇼츠 · 네이버 클립** | 릴스 재활용 | 릴스와 동일 (추가 제작 0) | 업로드만 |
| **네이버 플레이스** | 지역 검색 · 신뢰 | 블로그 글마다 소식 공유 | 1분 |

> 인스타를 주 7개에서 줄이는 이유: 블로그 → 인스타 유입은 2%뿐이고, 상담 전환은 블로그·플레이스·카톡에서 더 직접적으로 나와요. 줄인 시간은 **현장 사진·현장 노트**에 씁니다.

## 6. 블로그 방향 (요약)

1. **시리즈 4개로 고정** (호두네식)

   - 【마포·서대문 아파트】 `단지명 + 동 + 특징 + 실거래·전세 정리` — 그랑자이점
