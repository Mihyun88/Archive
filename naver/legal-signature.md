## 어디서 넣나요? (PC 기준, 순서대로)

> 네이버 블로그에는 "모든 글에 자동으로 붙는 서명" 기능이 따로 있지 않아요. 이전 답변에서 "하단 서명에 고정하면 자동으로 들어간다"고 한 건 정확하지 않았어요. 아래 3곳을 같이 쓰는 게 가장 확실합니다.

### ① 글쓰기 템플릿 저장 → 새 글마다 1번 클릭 (핵심)
1. PC에서 **블로그 → 글쓰기** (스마트에디터 ONE)
2. 본문에 위 **A안**을 붙여넣고, 카톡 채널은 링크 버튼, 위치는 **장소(지도) 버튼**으로 사무실 등록
3. 오른쪽 위 **[템플릿] → [내 템플릿] → [현재 글 저장]** → 이름: `착한언니 하단 서명`
4. 앞으로 새 글을 쓸 때 **[템플릿] → [내 템플릿] → 착한언니 하단 서명** 을 먼저 불러오고 그 위에 본문 작성
   - 매물 글은 B안까지 넣은 템플릿을 `착한언니 매물 글`로 하나 더 저장

### ② 블로그 위젯 (PC 화면 사이드바에 항상 노출)
1. **내 블로그 → 관리 → 꾸미기 설정 → 레이아웃·위젯 설정**
2. 아래 **[+위젯 직접등록]** → 이름 `중개사무소 정보`, 내용에 A안 중 사무소 4줄 입력 → 등록 → 사이드바에 배치 → 적용
   - 모바일 화면에는 위젯이 안 보여서 ①이 꼭 필요해요.

### ③ 블로그 소개글 (프로필)
1. **관리 → 기본 설정 → 블로그 정보 → 블로그 소개글**
2. 지금 소개글 마지막 줄 아래에 추가:
```

마포그랑자이(착한언니)부동산공인중개사사무소
등록번호 11440-2022-00085 · 대표 신혜선 · 02-707-3434
```
