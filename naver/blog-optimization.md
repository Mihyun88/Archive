## 3. 글 1편 작성 공식 (복붙용 템플릿)

### 제목
```
[검색어] + [구체 숫자/대상] + [결과·손실]
예) 등기부등본 보는법, 계약 전 이 2곳만 보세요 (갑구·을구 위험 신호)
예) 잔금 준비 순서 D-30부터 D-day까지, 순서 틀리면 대출 안 나와요
```
- 검색어는 **제목 맨 앞**에, 제목 길이는 **25~35자**
- 인스타 표지 제목(손실형)을 그대로 쓰지 말고 **사람들이 실제로 치는 말**로 바꾸기
  - ❌ "이 단어 모르고 재건축 사지 마세요" → ✅ "재건축 용어 정리, 관리처분인가·이주비·분담금 뜻 6가지"

### 본문 구조
```
① 결론 3줄 요약 (AI 브리핑·바쁜 독자용)  ← 가장 중요
② 대표 이미지 1장 (인스타 카드 1장을 블로그용 가로/정사각으로 재편집)
③ 소제목 1: 왜 중요한가 + 현장 사례 한 줄 ("지난달 잔금 날 실제로 ~")
④ 소제목 2~4: 본문 (표 1개, 번호 목록, 체크박스형)
⑤ 자주 묻는 질문 2~3개 (Q/A 형식 — 질문형 검색어를 그대로 소제목에)
⑥ 함께 보면 좋은 글 2~3개 (내 블로그 내부 링크)
⑦ 상담 박스 + 법정 표시 서명
```

### 꼭 지킬 것
| 할 것 | 하지 말 것 |
|---|---|
| 직접 만든 카드·현장 사진·서류 실물(개인정보 가림) | 다른 블로그·뉴스 문장/이미지 복사 |
| 검색어는 제목 1회 + 본문에 자연스럽게 3~5회 | 같은 키워드 10회 이상 반복, 흰 글씨 숨김 키워드 |
| 태그 5~10개 (검색어 + 지역 + 브랜드) | 태그 30개 꽉 채우기 |
| 출처 링크는 국토부·청약홈·법령정보 등 공식 1~2개 | 외부 링크 여러 개, 단축 URL, 오픈채팅 링크 남발 |
| 발행 후 최소 수정 (오탈자 정도) | 발행 직후 제목·본문 여러 번 크게 수정 |
| 숫자(실거래가·대출·세금)는 원문 확인 후 날짜 명시 | AI가 만든 숫자 그대로 게시 |

> 인스타 캡션을 그대로 붙여넣으면 정보량이 부족하고, 같은 문장이 여러 플랫폼에 깔려 **유사 문서**로 묶일 수 있어요. 카드 내용은 **뼈대로만 쓰고 문장은 새로** 써주세요.

## 7. 발행 후 점검 (매주 금요일 10분)

| 체크 | 방법 | 기준 |
|---|---|---|
| 검색 노출(누락) 여부 | 네이버에서 **제목 전체를 그대로** 검색 | 안 나오면 1~2일 더 기다린 뒤에도 없으면 누락 → 다음 글 패턴 점검 |
| 유입 키워드 | 블로그 통계 → 유입분석 → 검색 유입 | 예상 못 한 키워드가 들어오면 그 키워드로 후속 글 |
| 체류 시간 | 통계 → 평균 사용 시간 | 1분 미만 글은 결론 요약·표 보강 |
| 전환 | 카톡 채널 유입 경로 / 톡톡 문의 수 | 상담 박스 위치·문구 A/B |

### 이런 신호가 보이면 바로 멈추고 점검
- 갑자기 모든 글이 제목 검색에도 안 나옴 → 최근 글의 외부 링크·복사 이미지·반복 키워드 확인
- 방문자는 느는데 체류 10초 이하 → 제목과 본문이 안 맞는 '낚시형' 제목 수정
