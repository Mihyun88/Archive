### 데이터가 말해주는 것

**1. 이 블로그를 키우는 건 '고유명사' 검색이다**
유입 검색어 상위 16개가 전부 **건물명·단지명·브랜드명**이에요.
`신촌자이엘라` `신촌 오피스텔` `마포더클래시 18평` `신촌 현대벤처빌` `신촌포스빌` `유씨유이대` `핀란드타워` `이대더가온` `고덕강일3단지 59` `고덕강일3단지 견본주택` …
→ "잔금 체크리스트", "가계약금" 같은 **일반 정보 키워드는 TOP 20에 한 편도 없어요.** 언론·대형 블로그와 경쟁이라 밀리는 거예요.

**2. TOP 20 중 11편이 신촌·이대 오피스텔/마포 신축 글**
2022년, 2025년 글도 여전히 조회가 나와요(G&P나인 2022, 마에스트로·리브하임·푸르지오시티 2025). 건물명 글은 **한 번 써두면 몇 년간 검색**돼요. 그리고 이 검색을 하는 사람은 **실제로 집을 구하는 사람 = 상담 고객**이에요.

**3. 정보 글은 '이름 붙은 이슈'만 뜬다**
고덕강일3단지(단지명) 371, 토지거래허가구역 실거주 유예(제도명+날짜) 204, 광명 하안주공(단지명) 145, 일시적 2주택 10월 1일(제도명+날짜) 121.

**4. 중복 글이 조회를 반으로 쪼갰다**
핀란드타워 글 2개가 **99 + 70**으로 나뉨. 합쳤으면 169로 TOP 5 안. → **조회 많은 쪽(99)만 남기고 다른 하나 비공개**

**5. 브랜드 검색이 생기고 있다**
`착한언니복덕방` `착한언니부동산` `착한언니 복덕방` 합계 약 2.3% → 인스타·플레이스 보고 찾아오는 사람. 블로그명과 프로필에 **'착한언니부동산'** 표기도 같이 넣어두면 표기 흔들림까지 잡혀요.

**6. 인스타 → 블로그 유입은 2%뿐**
인스타는 카톡 채널로 바로 보내는 게 맞고, 블로그는 **검색 → 상담**의 별도 통로로 운영. 인스타 주제를 블로그에 그대로 옮기는 건 우선순위를 낮춥니다.

**7. 구글이 21%**
네이버 블로그도 구글에 잘 걸려요. 구글은 **제목 + 첫 문단**을 크게 보니, 첫 문단에 단지명·지역·핵심 숫자를 넣어 두면 두 곳 다 잡혀요.

### 그래서 블로그 전략을 이렇게 바꿉니다
| 비중 | 글 종류 | 예시 |
|---|---|---|
| **50%** | **건물·단지 글** (신촌·이대 오피스텔, 마포·서대문 아파트) | 「신촌포스빌 오피스텔 구조·월세 시세 2026」, 「마포그랑자이 59㎡ 84㎡ 실거래가 정리」 |

| 0% | 일상·여행 (고베 마라톤 등) | 새로 쓰지 않기 (기존 글은 유지) |

### 바로 할 일 TOP 5 (이번 주)
1. 핀란드타워 중복 글 중 **조회 70인 쪽 비공개**
2. 유입 검색어에 있는데 **전용 글이 약한 건물** 확인 → `신촌 현대벤처빌` `신촌포스빌` `유씨유이대` `이대더가온` 각각 「건물명 + 구조·시세·장단점 2026」 글 (현장 사진 필수)
3. TOP 20 오래된 건물 글(2022·2025)에 **2026 시세 한 단락 + 사진 추가하고 제목에 2026** 반영 (새 글 X, 기존 글 수정)
4. 고덕강일3단지 글 하단에 다음 청약 단지 글 링크 → 같은 형식으로 **11월 청약 단지별 글** 작성 (키워드 `단지명 + 59 / 견본주택 / 분양가`)
5. 모든 오피스텔 글 하단: 법정 표시 + 「이 건물 매물 문의 → 카톡」 버튼

### 운영 원칙
- 블로그 주제는 계속 **'부동산 하나'** 로 유지 — 지역이 넓어져도 주제가 같으면 C-Rank에 문제 없어요.

## 1. 네이버가 글을 고르는 기준 (실무용 요약)

| 기준 | 의미 | 우리가 할 일 |

## 3. 글 1편 작성 공식 (복붙용 템플릿)

### 제목
```
[검색어] + [구체 숫자/대상] + [결과·손실]
예) 등기부등본 보는법, 계약 전 이 2곳만 보세요 (갑구·을구 위험 신호)
예) 잔금 준비 순서 D-30부터 D-day까지, 순서 틀리면 대출 안 나와요
```
- 검색어는 **제목 맨 앞**에, 제목 길이는 **25~35자**
- 인스타 표지 제목(손실형)을 그대로 쓰지 말고 **사람들이 실제로 치는 말**로 바꾸기
  - ❌ "이 단어 모르고 재건축 사지 마세요" → ✅ "재건축 용어 정리, 관리처분인가·이주비·분담금 뜻 6가지"

### 본문 구조
```
① 결론 3줄 요약 (AI 브리핑·바쁜 독자용)  ← 가장 중요
② 대표 이미지 1장 (인스타 카드 1장을 블로그용 가로/정사각으로 재편집)
③ 소제목 1: 왜 중요한가 + 현장 사례 한 줄 ("지난달 잔금 날 실제로 ~")
④ 소제목 2~4: 본문 (표 1개, 번호 목록, 체크박스형)
⑤ 자주 묻는 질문 2~3개 (Q/A 형식 — 질문형 검색어를 그대로 소제목에)
⑥ 함께 보면 좋은 글 2~3개 (내 블로그 내부 링크)
⑦ 상담 박스 + 법정 표시 서명
```

### 꼭 지킬 것
| 할 것 | 하지 말 것 |
|---|---|
| 직접 만든 카드·현장 사진·서류 실물(개인정보 가림) | 다른 블로그·뉴스 문장/이미지 복사 |
| 검색어는 제목 1회 + 본문에 자연스럽게 3~5회 | 같은 키워드 10회 이상 반복, 흰 글씨 숨김 키워드 |
| 태그 5~10개 (검색어 + 지역 + 브랜드) | 태그 30개 꽉 채우기 |
| 출처 링크는 국토부·청약홈·법령정보 등 공식 1~2개 | 외부 링크 여러 개, 단축 URL, 오픈채팅 링크 남발 |
| 발행 후 최소 수정 (오탈자 정도) | 발행 직후 제목·본문 여러 번 크게 수정 |
| 숫자(실거래가·대출·세금)는 원문 확인 후 날짜 명시 | AI가 만든 숫자 그대로 게시 |

> 인스타 캡션을 그대로 붙여넣으면 정보량이 부족하고, 같은 문장이 여러 플랫폼에 깔려 **유사 문서**로 묶일 수 있어요. 카드 내용은 **뼈대로만 쓰고 문장은 새로** 써주세요.
