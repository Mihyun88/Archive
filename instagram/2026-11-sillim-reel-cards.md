### 수정본
```
[0~5초 | 과거 신림 사진 ↔ 지금 3구역 단지]  자막: #광고 도서협찬
"20년 가까이 멈춰 있던 신림 재개발,
 지금 구역마다 단계가 완전히 달라요."

[5~13초 | 3구역 단지 + 실거래 자막]
"3구역은 이미 서울대벤처타운역 푸르지오 571세대가 입주했어요.
 84㎡ 실거래가 올해 9월 11억 8천이었고요.
 대신 역까지 오르막이 있다는 건 직접 걸어보세요."
 (자막: 국토부 실거래 2026.9 / 호가를 쓰면 '○월 ○일 네이버 호가' 표기)

[13~22초 | 2구역 공사 현장]
"바로 앞 2구역은 관악구 현황 기준 착공 단계예요.
 1,430세대가 들어설 예정이고요."

[22~32초 | 1구역 지도]
"제가 더 눈여겨보는 건 1구역이에요.
 4,185세대, 사업시행인가까지 받았어요.
 1~3구역을 합치면 6,186세대 —
 입주 시기는 구역마다 다르지만, 생활권이 통째로 바뀌는 거죠."

[32~40초 | 책 표 화면]
"빠숑 김학렬 소장님 책에서는
 관악구를 2026년 20위, 2032년 17위로 전망했어요.
 지역 전체에 대한 조건부 전망이라는 것도 같이 봐 주세요."

[40~48초 | 책 + 자료 표지]
"신림 말고도 앞으로 6년 눈여겨볼 지역이 더 있더라고요.
 서울·수도권 22개 지역 순위를 정리해 뒀어요.
 팔로우하고 댓글에 '오를 곳' 남기시면 자료 보내드리고,
 11월 30일에 책 3권 추첨해서 드릴게요."
```

**캡션 (마지막 줄 고정)**
```
#광고 #도서협찬 신림 재개발, 구역마다 단계가 달라요.
3구역 입주 완료 · 2구역 착공 · 1구역 사업시행인가 (관악구 현황 2026.10.26)

📩 댓글에 '오를 곳' → 22개 지역 순위 자료 DM (팔로워분께 발송)
🎁 11/30 《이제부터는 오를 곳만 오른다》 3권 추첨 (팔로우 + 댓글)
📞 상담은 프로필 링크 → 카톡 채널
```

## 2. 카드뉴스 (5장 · 보상형)

| 장 | 제목 | 본문 | 디자인 |
|---|---|---|---|
| **1 표지** | **신림 재개발, 10개 구역 단계가 다 달라요** | 소제목: 입주 · 착공 · 인가 · 이제 출발 / 우하단 배지 `💬 '오를 곳' → 자료` · 좌상단 `#광고 도서협찬` | 3구역 단지 사진 배경 |
| **2 한눈에** | 지금 어디까지 왔나 | 3구역 **입주** (이전고시 26.5) / 2구역 **착공** (구청 현황 26.10) / 1구역 **사업시행인가** (25.3) / 8구역 **조합설립** (26.10) / 5·6구역 **구역지정** (26.2·5) / 4·7·9·10 초기 | 단계 타임라인 막대 |
| **3 숫자** | 6,186세대의 진짜 의미 | 1구역 4,185 + 2구역 1,430 + 3구역 571 = 6,186 / **3구역은 이미 입주** → "입주 시기가 다른 6천여 세대" | 막대 3개 + 3구역에 '입주완료' 스티커 |
| **4 교통** | 여의도·강남, 실제로는? | 여의도: 신림선 전 구간 **16분** (서울시 발표) / 강남: 2호선 신림역 → 강남역 **8개 역** / 난곡선: **예타 결과 12월 예정** · 서부선: 착공 일정 확인 필요 | 노선 간이도 (자체 제작) |
| **5 체크 + CTA** | 사기 전에 이 3가지 | ① 권리산정기준일 ② 관리처분 후 지위양도 제한 ③ 토지거래허가 대상 / 하단: `💬 '오를 곳' → 22개 지역 순위 자료` · `🎁 11/30 책 3권 추첨` | 체크박스형 |

> 숫자·날짜는 블로그 글과 동일하게 유지. 발행 직전 관악구 현황표 갱신 여부 확인.
