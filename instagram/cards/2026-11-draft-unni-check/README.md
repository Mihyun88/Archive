## 새 기획 규칙
1. 시리즈 이름 「언니 체크」 고정 (표지 왼쪽 위 배지) → 다음 편 기대
2. 표지 = 행동 문장 + 큰 숫자 + 비틀기 한 줄 ("등기부만 보면 안 보이는 빚")
3. 2장 = 상식 비틀기 (빙산 그림)
4. 한 장 = 서류 1개 · "이 순서로 보세요" 3줄 이하 · 어디서/누가
5. 끝에서 2번째 = 캡처용 한 장 정리 (저장 유도 핵심)
6. 마지막 = 저장·공유 + 다음 편 예고
7. 피드 하루 1개, 청약 속보는 주 1개
