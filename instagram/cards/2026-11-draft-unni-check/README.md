## 새 기획 규칙
1. 시리즈 이름 「언니 체크」 고정 (표지 왼쪽 위 배지) → 다음 편 기대
2. 표지 = 행동 문장 + 큰 숫자 + 비틀기 한 줄 ("등기부만 보면 안 보이는 빚")
3. 2장 = 상식 비틀기 (빙산 그림)
4. 한 장 = 서류 1개 · "이 순서로 보세요" 3줄 이하 · 어디서/누가
5. 끝에서 2번째 = 캡처용 한 장 정리 (저장 유도 핵심)
6. 마지막 = 저장·공유 + 다음 편 예고
7. 피드 하루 1개, 청약 속보는 주 1개

## 근거
- 주택임대차보호법 제3조의7 (임대인 정보 제시 의무: 확정일자·보증금 정보, 국세·지방세 납세증명서)
- 국세징수법 제109조 · 시행령 (보증금 1천만 원 초과, 계약일~임대차 개시일 임대인 동의 없이 미납국세 열람)
- 주택임대차보호법 제3조의6 (계약 전 확정일자 정보는 임대인 동의 필요)

## 3장 실물
대표님 제공 등기부 「주요 등기사항 요약」 사진 사용. 소유자 이름·주민번호·주소·건물 주소 가림 (원본은 저장소에 올리지 않음).
