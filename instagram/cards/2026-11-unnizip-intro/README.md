## 2. 블로그 (네이버 블로그 1편)

**목표**: 검색으로 들어온 사람이 사이트를 바로 써보게 하기 (QR·링크 클릭)
**제목 후보**
1. 현금 3억이면 서울 어디까지? 공인중개사가 만든 무료 부동산 계산기 6가지
2. 부동산 강의 안 들어도 돼요, 내 동생한테 알려주듯 만든 계산기 사이트
3. 집 사기 전에 꼭 계산해봐야 할 5가지 (예산·시세·부대비용·동네·정책)

**검색 키워드**: 부동산 계산기, 내 집 마련 예산, 아파트 적정가, 취득세 계산, 자취방 동네 추천, 서울 아파트 시세
**이미지**: 카드뉴스 1·2번 + `src/shot-*.png` 실제 화면 + `blog-qr.png`
**QR/링크**: `blog-qr.png` → https://unnizip.kr/tools/?utm_source=naver_blog&utm_medium=post&utm_campaign=tools_intro (블로그에서 몇 명 들어왔는지 따로 볼 수 있게 표시를 달았어요)

### 글 구성 (약 2,000자)
1. **도입: 이런 고민 해보셨죠?** (카드 2번 이미지)
   "다들 집 사라는데, 뭐부터 봐야 할지 모르겠어요." 상담하면서 제일 많이 듣는 말이에요. 강의는 30만 원, 100만 원… 그런 거 안 들어도 되게, 동생한테 알려준다는 마음으로 만들었어요.
2. **01 예산 계산기**: 현금·소득만 넣으면 대출 한도(LTV·스트레스 DSR)와 취득세까지 계산 → 살 수 있는 단지 TOP 30. 예시: 현금 3억 → 최대 5억 9,174만 원. ⭐ 대출은 은행 상담으로 확인.
3. **02 자취 동네**: 학교·직장 + 보증금·월세·통근시간 → 실제 신고된 월세로 동네 비교. 예시: 연세대 기준.
4. **03 가격 검토**: 단지·면적·희망 가격 → 최근 거래 대비 몇 %. "괜찮은 가격이에요" 들어도 내 눈으로 확인하기.
5. **04 부대비용**: 7억 아파트면 약 1,783만 원. 잔금 체크리스트(노션)도 함께 소개.
6. **05 시황·정책 뉴스**: 매주 서울 25개 구 + 착한언니 한 줄 요약 + 정책 원문 링크.
7. **마무리**: QR + 링크, "모르겠으면 그냥 물어보세요" + 카톡 채널 안내. 두 사무소(신촌자이엘라·마포그랑자이) 소개 한 줄.

**주의**: 블로그에도 이메일 주소는 넣지 않기. 연락은 카톡 채널·전화만.

## 3. 릴스 (25~30초, 세로 9:16)

**콘셉트**: "동생이 물어본다 → 언니가 폰으로 보여준다" 대화형. 얼굴 안 나와도 되고, 손 + 폰 화면 녹화로 충분해요.
**준비물**: 폰 화면 녹화 (unnizip.kr/tools), 사무실 책상이나 카페 배경, 손으로 폰 들고 찍기 1~2컷

| 시간 | 화면 | 자막 (크게) | 말/내레이션 (선택) |
|---|---|---|---|
| 0~2초 | 카톡 대화 화면 느낌의 자막만 | **"언니, 나 3억 있는데 집 살 수 있어?"** | (알림음 효과) |
| 2~4초 | 손에 든 폰 → unnizip.kr 열기 | "잠깐만, 이거 넣어봐" | |
| 4~9초 | 예산 계산기 입력 → 결과 | **현금 3억 → 최대 5억 9,174만 원** | "대출 한도랑 취득세까지 알아서 계산돼" |
| 9~13초 | 단지 TOP 30 스크롤 | "살 수 있는 단지까지 보여줌" | |
| 13~17초 | 부대비용 탭 | **집값 말고 1,783만 원 더 들어요** | "세금·등기·복비 미리 봐야 해" |
| 17~21초 | 가격 검토 결과 | "이 가격 비싼 건지도 확인" | |
| 21~25초 | 자막 화면 (남색 배경) | **강의 안 들어도 돼요<br>동생한테 알려주듯 만들었어요** | |
| 25~30초 | 마지막 카드(8번) | **프로필 링크 → 무료** | "저장해두고 집 볼 때 써" |

**커버**: 카드 1번 이미지 그대로 (피드 통일감)
**음악**: 인스타 인기 오디오 중 잔잔하고 경쾌한 것, 자막이 주인공이라 소리 없이도 이해되게
**캡션**: 짧게
```
동생이 "3억으로 집 살 수 있어?" 물어봐서 보여준 사이트 🏠
무료 · 회원가입 없음 · 프로필 링크에서 바로!
📌 저장해두고 집 볼 때 꺼내 쓰세요
#부동산계산기 #내집마련 #착한언니복덕방
```
**올리는 순서**: 카드뉴스 먼저 → 3~4일 뒤 릴스 → 같은 주에 블로그. 릴스 캡션에 "자세한 건 고정 게시물 카드뉴스"로 연결.
