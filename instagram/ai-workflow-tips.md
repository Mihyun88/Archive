# Claude · ChatGPT · Gemini 역할 분담 팁

> 아카이브 사이트에 정리한 데이터(릴스 등급, 성공·실패 원인, 노션 소재 DB, 11월 계획)를 기준으로
> 세 AI를 **겹치지 않게** 나눠 쓰는 방법이에요.
> AI 서비스의 기능은 자주 바뀌니, 각 기능은 쓰기 전에 지원 여부를 한 번 확인하세요.

## 2. 사이트 데이터를 활용한 소재 발굴 5가지

### ① C등급 릴스 되살리기 (Claude)
사이트에 C등급이 12개 있어요. 그중 **소재는 강한데 구조 때문에 실패한 것**(예: 10년 월세 4,655, 등기부등본 4,032)은 재촬영할 가치가 있어요.
```
[사이트의 C등급 릴스 메모 붙여넣기]
위 릴스 중 '소재는 좋은데 구조 문제'인 것만 골라서,
우리 대본 공식(0~3초 숫자 훅 / 15초 예고 / 40~50초 / 키워드 CTA)으로
재촬영 대본을 써줘. 숫자는 【 】 자리표시로 남겨줘.
```

### ② S등급 공식으로 "변주" 만들기 (ChatGPT → Claude)
S등급 6개는 공식이 분명해요. 가격 비교, 판정형, 질문 뒤집기, 대조형, 지역 족보, 리스트예요.
1. **ChatGPT**에 공식 하나를 주고 "이 구조로 부동산 소재 20개"를 요청하세요.
2. 나온 목록을 **Claude**에 넣고 "35~44세 실수요 매수자 타깃이 아닌 것, 세입자 분쟁형은 빼고 상위 5개"로 걸러달라고 하세요.

### ③ 경쟁 쇼츠 구조 해부 (Gemini)
같은 분야에서 조회수가 높은 쇼츠 링크 3~5개를 Gemini에 넣고 이렇게 요청하세요.
```
각 영상의 0~3초 첫 문장, 정보가 나오는 순서, CTA 위치, 총 길이를 표로 정리해줘.
```
결과를 Claude에 넘기면 우리 대본 공식과 비교해서 다른 점을 짚어줘요.

### ④ 노션 소재 DB 자동 우선순위 (Claude)
사이트의 "노션 소재 진단"처럼, 새 소재를 노션에 넣을 때마다 이렇게 요청하면 돼요.
```
노션 릴스 DB에 새로 들어온 소재를
지난 성과 패턴(가격비교·판정형·리스트 = 상 / 세입자 분쟁·자취·학부모 = 하)
기준으로 우선순위 매겨서 노션에 메모해줘.
```

### ⑤ 댓글 보상 자료 대량 제작 (Claude + 노션)
11월 카드뉴스 9개에는 보상 자료가 9개 필요해요. Claude에게 이렇게 요청하면 됩니다.
```
11/4 '잔금' 키워드 보상 자료를 노션 페이지로 만들어줘.
(기존 '첫 집, 내 현금으로 어디까지?' 페이지 형식 참고)
```

## 4. 꼭 지킬 것
- **숫자는 AI가 말한 그대로 쓰지 마세요.** 실거래가, 대출 한도, 청약 일정, 세법은 반드시 원문으로 확인하세요. 계정의 신뢰도(12년차 중개사)가 가장 큰 자산이에요. 8/11 메이플자이 정정 사례처럼 한 번 틀리면 정정 공지가 훅을 잡아먹어요.
- **같은 질문을 두 AI에 교차 검증**하세요. 답이 다르면 원문을 확인하라는 신호예요.
- **액세스 토큰이나 개인정보는 다른 AI에 붙여넣지 마세요.** 인스타 데이터 연동은 한 곳(Claude)에서만 하세요.
- 법률 문구(특약)는 AI 초안을 쓰더라도 **실제 계약서에 쓰는 문구로 직접 검수**하세요.
