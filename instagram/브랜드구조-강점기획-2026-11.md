# 착한언니복덕방 강점 기반 콘텐츠 구조 (2026-11-22)

## 포지션
- 변호사(쪼변): 사고 난 뒤 해결 / 라슈·카렌: 어디 살지 추천
- **착한언니: 사고 나기 전에 막는 사람 — "무사고 12년차, 말리는 중개사"**

## 강점 → 증거
| 강점 | 증거 |
|---|---|
| 현장 사례 (남이 못 지어냄) | 말린 계약 4가지, 15년 된 집 퇴실 정산, 등기 볼 때 갑구 소유자→을구 습관 |
| 말투·협상 감각 | 고수하수 "늘 잘 먹힘", 편집 쉬움 |
| 상황극 구성력 | 모녀 가계약금 대본 직접 작성, 레퍼런스 대본 수집 |
| 현장 인맥 = 진짜 숫자 | 이사업체 대표 통화 → 손없는날 숫자 |
| 실물 서류 | 등기부·매매약정 샘플 → 저장 102~2,281 |
| 사무실 2곳·직원 4명 | 상황극 상대역, 대단지 현장(신촌·마포) |
| 무료 자료 체계 | 노션 자료 + 언니집 계산기 → 댓글→DM 엔진 (잔금 릴스 댓글 720, +171 팔로우) |

약점: 정보성 조사·편집 부담, 시간·체력, 법 해설 권위는 변호사보다 약함 → 정보성은 카드로 위임, 법은 "현장 장면"으로만.

## 4개 기둥
| 기둥 | 형식 | 빈도 | 누가 | 목표 |
|---|---|---|---|---|
| ① 고수 vs 하수 | 30초 독백/2인, 오프닝·자막·엔딩 고정 | 주 3 | 대표님 촬영 | 도달·팔로우 |
| ② 이 계약, 제가 말렸어요 | 실제 말린 사례 상황극 40~50초 | 주 1 | 대표님+직원 | 신뢰·공유 |
| ③ 언니 체크 | 실물 서류 + 체크리스트 카드 | 주 2 | Claude 제작, 대표님 확인 | 저장·DM |
| ④ 언니 픽 | 10~15초 예산×출퇴근 리스트 릴스 (실거래가 + 현장 한 줄) | 격주 | Claude 제작, 대표님 확인 | 지역 상담 |

모든 게시물 끝 = 댓글 → 무료 자료 DM → 카톡 채널 → 상담.

## ② 말린 계약 시리즈 소재 (대표님 실제 경험)
1. 수리에 인색한 집주인
2. 너무 골목진 집
3. 유흥가 근처, 1층 노래방
4. 시세보다 높아 보증보험 안 되는 집
5. 15년 산 집 퇴실 정산 (집주인 vs 세입자)

## 한 주 작업 흐름
- 월 오전 1시간: 녹화 몰아서 (고수하수 3 + 말린계약 1)
- 대표님은 사례를 음성 메모로 1~2분 말하기만 → Claude가 대본화
- Claude: 대본, 카드, 캡션, 고정 댓글, DM 문구, 일정표
- 토: 주간 성과 정리 (기둥별 도달·저장·팔로우)
