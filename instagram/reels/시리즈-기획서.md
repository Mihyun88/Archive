## 시리즈별 예시 편 (훅·비틀기만, 대본 아님)
1. 하수 vs 고수 「가격 물어볼 때」 — 하수: 깎아 달라는 말 / 고수: 가격 대신 "언제 비워 주세요?" (매도인 사정을 묻는다). 마지막 쌍: 고수인 줄 알았던 쪽이 하수
2. 상황극 「가계약금 50만 원」 — 첫 장면: "돌려주세요" "못 드려요" → 3일 전 카톡 → 반전: 날짜·금액까지 합의한 문자 ⚠️ 법률 확인 필요
3. 대장 「지난달 가장 많이 팔린 단지」 — 숫자 먼저("한 달에 ○채") → 이름 공개 → 반전(대장 아님?) ⚠️ 데이터로 확인되면만
4. 튜토리얼 「실거래가, 취소된 거래 거르기」 — 화면 동그라미 → 저는 여기 봐요 ⚠️ 대표님 앱 화면으로 확인

## 레퍼런스 비교로 확정한 규칙 (11/17)
- 터진 것: 보증금 안 주는 집주인 상황극 · 배액배상 상황극 · 하안주공 재건축 독백(10만) · 손님 문의 하수/고수(20만) · 잔금 하수/고수(100만)
- 약했던 것: 비데티슈 상황극(2만, 평균 시청 17.8초로 붙잡긴 했지만 확산 약함) · 은마 재초환 독백(5,482)
1. **시청자 편이 이긴다**: 시청자가 감정 이입하는 쪽(세입자·매수인)이 지식이라는 무기로 상대(욕심내는 집주인·매도인)를 이겨야 통쾌함 → 공유. 비데티슈는 시청자 쪽(세입자)이 잘못한 쪽이라 찔리기만 함
2. **판돈이 커야 한다**: 보증금, 2억 상승, 잔금일처럼 큰돈·날짜. 수리비 몇만 원은 남 일
3. **독백은 경고보다 기회**: 하안주공 = 증거(신고가) → 다음 타자(바로 옆) → 함정 → 자료. 은마 재초환 = 남의 단지 부담 경고만
4. **정보는 대사 속 무기**: 해설자 없이 인물이 쓰는 말로
5. v2의 "당연히 이길 줄 안 쪽이 진다"는 **"욕심낸 쪽이 진다"**로 수정

## 하수vs고수 썸네일·훅 표준 (11/23 · 영팀장 200만 구조 참고)
- 상단 2줄 가운데: 1줄 흰색 = 훅 ("한국인 99%가 모르는" / "1%만 아는" / "~하면 후회하는 N가지") · 2줄 노란색 = 주제+이득 ("전세 계약할 때 돈 지키는 꿀팁")
- 숫자(99%, N가지)와 돈/이득 단어는 노란색
- 머리 위 라벨: 검정 둥근 박스 · 하수 흰 글씨 / 고수 노란 글씨 ("전세 하수" "전세 고수"처럼 주제어 붙이기)
- 1인 2역 같은 옷 상반신 · 밝은 배경 · 하수 손동작 / 고수 팔짱
- 대본: "나는 ~" 대구 · 항목당 6~7초 · 대사마다 증빙 화면(앱·서류·문자) · 끝은 고수 단독 + 댓글 키워드
- 훅 문구 은행: 한국인 99%가 모르는 ~ / 1%만 아는 ~ / ~하면 후회하는 N가지 / 모르면 N백만 원 날리는 ~
