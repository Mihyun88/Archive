# 착한언니 릴스 4대 시리즈 기획서 (2026.11.17 대표님 확정 방향)

> 공통 원칙: 대본은 구조 확정 후에만 · 겁주기/훈계/자랑 금지 · 숫자는 출처·기준일 · 법률은 전문가 확인 문구
> 교훈(11/16): 설명이 주인공이면 재미없다. **인물·대결·실제 대사**가 주인공이어야 한다.

## 1. 하수 vs 고수 (꿀팁)
- **규칙: 하수 대사 = 일반 사람이 실제로 하는 말** (대표님이 손님에게 들은 그대로). 고수 대사 = 중개사가 실제로 하는 말.
- 하수가 바보가 아니라 "나도 그렇게 말하는데?"여야 공감이 생김
- 상황 슬롯: 집 보러 가서 첫마디 / 가격 물어볼 때 / 깎아 달라 할 때 / 대출 물어볼 때 / 가계약금 보내기 전 / 층·동 고를 때 / 급매 봤을 때 / 중개사에게 매물 부탁할 때
- 재료: 대표님이 들은 손님 말 (하수 대사 은행)

## 2. 상황극 (법령·판례를 어렵지 않게)
- **규칙: 조문·판례 용어는 대사에 안 씀.** 인물 2명의 갈등 → 결말 → 마지막 자막 한 줄로 근거(법 조항·출처)
- 후보: 가계약금 돌려받을 수 있나 / 계약금 배액배상 / 집주인이 집 팔면 세입자는 / 실거주한다며 갱신 거절 / 퇴실 원상복구 정산 / 중도금 낸 뒤 해제
- 에피소드마다 사실 확인(법령 원문·대한법률구조공단 등) 후 촬영, 결론은 "상황마다 달라요" 열어두기
- 배우: 직원분 1명 + 대표님

## 3. 대장 아파트 (큰 단지 · 거래량 많은 곳) — 매 편 보여주는 방식 교체
- 데이터: 국토부 실거래(거래량·가격), 세대수·연식(건축물대장/공동주택 정보) — 매 편 기준일 명시
- 형식 은행 (돌려 쓰기)
  a. **가격 맞히기 퀴즈**: 단지 외관 → "얼마일까요?" → 실거래 공개
  b. **대장 vs 대장 옆**: "싸게 나온 대장 옆 아파트" (대표님 고수 대사에서 출발)
  c. **그 돈이면**: 같은 예산(예: 10억)으로 살 수 있는 대장 3곳
  d. **이번 달 가장 많이 팔린 단지**: 월간 거래량 랭킹 (데이터 뉴스, 매달 고정)
  e. **대장 채점표**: 세대수·역까지 도보·학교·연식 점수판으로 채점
  f. **걸어서 몇 분**: 정문 → 역까지 실제로 걸으며 타이머 (현장 POV)
- 주의: "사세요" 아님, 정보 제공 톤. 특정 매물 광고처럼 보이지 않게

## 4. 초보 튜토리얼 (아파트 보는 법 · 앱 꿀팁)
- 화면 녹화 + 대표님 목소리. "이 앱은 여기서 이걸 보면 꿀팁"
- 에피소드 후보: 실거래가 진짜 보는 법(해제 거래 거르기) / 같은 단지 동·층별 가격 차 / 거래량 보는 법 / 등기부 3분 / 세대수·주차대수 / 전세가율 / 학교 배정 / 청약홈
- 화면은 대표님 폰 녹화가 원본 (앱 화면을 제가 추측해서 쓰지 않음)
