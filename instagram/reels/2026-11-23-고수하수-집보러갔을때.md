# 하수 vs 고수 — 집 보러 갔을 때 (G3 v1)

- 형식: 하수vs고수 (1인 2역 분할화면 또는 2인), 대사만 · 내레이션 X · 25초 내외
- 상태: 대본 초안 (대표님 확인 전)
- G1(창틀·모서리·천장, 수압·사진)과 겹치지 않게 **"다들 묻는 질문 → 고수는 다른 걸 묻는다"** 구조

## 레퍼런스 (구조만 참고)
- @yeongleader 「이사 하수 vs 고수」 200만 — 1인 2역 분할화면, 하수가 하는 '보통 행동' → 고수가 바로 대안. 설명 없이 행동 대비만.
- 대표님 잔금 하수/고수 100만 — 하수 = 그럴듯한 말, 고수 = 구체 행동 + 이유 한 줄.
- 대표님 문의 고수하수 20만 — 질문 하나만 바꿔도 대우가 달라짐.
- @knpbhs 「이거 누가 수리? 집주인 vs 세입자」 37만 — '옵션 수리 책임' 관심 높음 → 2번 쌍에 반영.

## 화면 상단 고정 자막
**집 보러 가서 "남향이에요?" 묻는 사람 = 하수**

## 대본

| # | 🙅 하수 | 🙆 고수 |
|---|---|---|
| 1 | (현관 들어서자마자) "남향이죠? 해 잘 들어요?" | (말없이 창가로 가서 앞 건물 거리부터 봄) "남향이어도 앞 건물이 붙어 있으면 낮에도 불 켜요." |
| 2 | "에어컨, 세탁기 옵션 다 있네요." | "이 에어컨 집주인 거예요? 전 세입자가 두고 간 거면 고장 나도 고쳐 줄 사람이 없어요." |
| 3 | "관리비 7만 원이면 싸네요." | "7만 원에 뭐 빠졌어요? 수도, 인터넷, 난방 따로면 그게 진짜 월세예요." |
| 4 | (창문 활짝 열고) "와, 뷰 좋다." | (창문 닫고 손 들어 '쉿') "1분만요." — (큰길 차 소리 / 윗집 쿵) — "매일 밤 들을 소리예요." |
| 5 | (집 둘러보며) "깨끗하게 쓰셨네요~" | (세입자에게 웃으며) "여기 몇 년 사셨어요?" — 세입자: "6년이요." |

**마지막 자막 (5번 직후, 고수 쪽 화면 정지)**
> 오래 산 집은, 살 만한 집이에요.
> 1년 만에 나가는 집이면 — 이유를 물어보세요.

(마지막 쌍이 반전: 제일 '잡담 같은' 질문이 사실 제일 중요한 질문)

## 촬영 메모
- 사람 사는 집 설정 → 사진 찍는 장면 X, 세입자는 뒷모습/목소리만
- 4번 소음은 효과음으로 처리 (실제 소음 녹음 불필요)
- 하수는 똑똑해 보이게: 메모장 들고 체크하는 모습 → "나도 저랬는데"
- 되묻기 없음 · 첫 대사 바로 용건
