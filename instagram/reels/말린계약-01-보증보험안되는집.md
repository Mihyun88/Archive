# 「이 계약, 제가 말렸어요」 1편 · 보증보험 안 되는 집 (상황극 · 약 45초) — 초안 v1

- 형식: 순수 상황극 (독백·내레이션 없음) · 대표님(언니) + 손님(직원 1명, 20대 후반 느낌)
- 장소: 사무실 상담 테이블 · 서류 한 장 · 휴대폰
- 감정선: 손님 들뜸 → 서운함·반발 → 중개사가 수수료를 포기하는 순간 반전 → 신뢰
- ✍️ = 대표님 실제 사례로 바꿀 곳 (금액·집 종류는 지어내지 않고 비워 둠)
- 연결 자료: 전세대출 특약 원문 + 계약 전 체크리스트 (11/6 자료)

## 대체 훅 (0~3초) — 고르기
- A (위) 언니: "이 집은… 제가 계약 안 해드릴게요."
- B 손님: "아니 다른 부동산은 된다는데, 왜 여기만 안 된대요?!"
- C 언니: "도장 찍으시기 전에, 이 숫자 두 개만 같이 봐요."

## 사실 확인 (대본에 단정 표현 없음)
- "거절 날 가능성이 커요": 전세보증금반환보증은 보증금이 주택가격 대비 일정 비율을 넘으면 가입이 어려움 (HUG 등 기관·상품마다 기준 다름) → 비율 숫자는 대사에 넣지 않음. 캡션에 넣을 경우 HUG 현행 기준 확인 후 표기
- "특약은 약속": 보증보험 가입 불가 시 계약 해제 특약 자체는 유효하고 유용함 → 특약을 깎아내리지 않고 "돌려받는 건 돈이 있어야" 로만 말함
- ✍️ 금액·집 종류는 대표님 실제 사례로
