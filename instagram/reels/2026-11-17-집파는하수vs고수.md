# 🎬 11/17(화) 릴스: 같은 단지, 한 집만 안 팔리는 이유 (집 파는 하수 vs 고수)

**형식**: 1인 2역 화면 분할 (왼쪽 🙅 하수 · 오른쪽 🙆 고수) + 카운트다운 3단계
**길이**: 40~45초 · **댓글 키워드**: `갈아타기` → 갈아타기 계산기 (11/12 카드와 같은 자료)
**근거**: 10/28 「집이 안 팔리는 사람 TOP5」(평균 시청 23.5초 · 계정 최고) 내용을 대조형으로 재구성 + 부린이 vs 고수(도달 10.6만) 포맷

**의상·소품**
- 하수: 후드티 또는 편한 옷, 휴대폰만 들고
- 고수: 셔츠·블라우스, 노트(실거래 출력물)
- 같은 거실을 배경으로 두 번 찍어 좌우로 붙이면 돼요.

## 대사표
| 시간 | 화면 | 자막 | 대사 |
|---|---|---|---|
| 0~3초 | 좌우 분할, 둘 다 휴대폰 보며 한숨 | **같은 단지, 같은 평형인데 한 집만 안 팔려요** | (본인 내레이션) "같은 단지, 같은 평형인데… 왜 한 집만 안 팔릴까요?" |
| 3~5초 | 자막 크게 | **집 파는 하수 vs 고수** | – |
| **1단계 · 가격** | | | |
| 5~11초 | 하수: 휴대폰으로 옆 단지 매물 보며 | 🙅 옆 단지 최고가 = 내 집 가격 | 하수: "옆 단지 15억에 팔렸대. 우리도 15억!" |
| 11~16초 | 고수: 실거래 출력물 펼치며 | 🙆 시장이 인정하는 가격에서 출발 | 고수: "그 집은 로열동에 올수리예요. 같은 면적 실거래부터 볼게요." |
| **2단계 · 내놓는 방법** | | | |
| 16~22초 | 하수: 전화 세 통, 매번 다른 금액 | 🙅 부동산마다 가격이 다 달라요 | 하수: "A부동산엔 15억, B엔 14억 5천, C엔… 14억?" |
| 22~26초 | 고수: 메모 한 장 | 🙆 가격은 하나로 | 고수: "어디서 보든 같은 가격이에요." |
| 26~28초 | 내레이션 자막 | 매수자는 광고 중 **제일 싼 값**에서 또 깎아요 | – |
| **3단계 · 집 보여주는 날** | | | |
| 28~33초 | 하수: 커튼 닫힌 어두운 거실 | 🙅 커튼 치고 불 끈 집 | 하수: (소파에 누운 채) "그냥 보고 가세요~" |
| 33~38초 | 고수: 커튼 열고 불 켜고 창문 열기 | 🙆 불 켜고 환기, 세입자에겐 미리 협조 | 고수: "첫인상 10초가 가격이에요." |
| **마무리** | | | |
| 38~42초 | 본인 정면 (화면 분할 해제) | **팔 때도 살 때도 '시장 가격'을 아는 사람이 이겨요** | "받고 싶은 가격이 아니라 시장이 인정하는 가격. 갈아타실 분이라면 이게 먼저예요." |
| 42~45초 | 자막 + 손가락으로 아래 가리킴 | 💬 댓글 '갈아타기' → 내 집 계산기 | "내 집으로 어디까지 갈아탈 수 있는지, 댓글에 '갈아타기' 남겨주세요." |

> 3단계에서 '세입자 협조'는 10/28 캡션의 2위 항목("부동산에 내놓기 전에 충분한 상황 설명과 협조를 구하세요")을 그대로 쓴 거예요.

🏠 같은 단지, 같은 평형인데
한 집만 안 팔리는 이유

차이는 딱 3가지예요.

🙅 옆 단지 최고가로 내 집 가격
🙆 같은 면적 실거래에서 출발

🙅 부동산마다 가격이 다름
🙆 어디서 보든 가격은 하나
