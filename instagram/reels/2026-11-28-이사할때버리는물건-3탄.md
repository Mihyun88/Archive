# 이사초보 vs 이사고수 — 이사할 때 99%가 그냥 버리는 물건 (3탄 v1 · 약 32초)
시리즈: 1탄 g7 「이사할 때 99%가 그냥 버리는 돈」 10만 4천(저장 2천) → 같은 틀로 '돈' → '물건'
형식: 1인 2역 같은 옷 · 라벨 「이사초보」(흰) vs 「이사고수」(노랑) · 항목당 6~7초 · 증빙 화면

## 썸네일
- 1줄 흰색: 이사할 때 99%가
- 2줄 노란색: 그냥 버리는 물건

## 근거·확인
- 1: 아름다운가게 온라인 기증 신청 → 방문 수거 · 기부금 영수증 발급 → 기부금 세액공제 (공제율 단정 X) · https://www.beautifulstore.org ✍️ 방문 수거 최소 수량은 신청 화면 기준
- 2: 당근 판매 — 일반 정보 (화면은 대표님 폰 캡처 또는 예시)
- 3: 폐가전제품 무상 방문수거 — 대형(냉장고·세탁기 등) 1개도 무료, 소형은 5개 이상 · 전화 1599-0903 · 15990903.or.kr · 앱 '폐전자제품 모두비움' (서울시·인천시·파주시 안내 기준, 지역마다 다를 수 있음) · "스티커값 만 원 넘게"는 냉장고 대형폐기물 수수료가 구·크기별로 다름 → ✍️ 마포·서대문 수수료표로 확인 후 숫자 조정 (확인 전엔 "스티커 돈 내고"로)
- 4: 이사비는 짐 양에 따라 차량 톤수·인원이 정해짐 (일반 기준)
- 영팀장 200만 영상에 '폐가전 무상수거' 항목이 있음 → 표현은 겹치지 않게, 빼고 싶으면 '남은 종량제봉투'(1탄 중복이라 비추) 대신 '이삿짐 박스 중고 거래'로 교체 가능
- DM: 기존 노션 「이사할 때 돈 아끼는 체크리스트」 (짐 줄이기 섹션 있음) · 키워드 '꿀팁' 그대로 → 폐가전 무상수거 한 줄은 노션에 추가 예정
