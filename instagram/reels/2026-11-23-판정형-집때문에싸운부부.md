# 집 때문에 싸운 부부, 숫자로 판정해 드림 — 판정형 시리즈 기획 (J1 v1)

## 1. 왜 510만이 나왔나 (@lawyer.jung.sw 「너네 싸운 이유 과실비율 알려드림」, 9초)
말이 좋아서가 아니라 아래 다섯 개가 동시에 맞았기 때문.

| # | 작동 원리 | 그 영상에서 |
|---|---|---|
| ① | **누구나 지금 품고 있는 억울함** | 애인이랑 싸운 일은 모두에게 있고, 대부분 결론이 안 난 상태 |
| ② | **"내가 맞지?"를 객관적으로 확인받고 싶은 욕구** | 감정싸움에 '과실비율'이라는 객관 잣대를 약속 |
| ③ | **싸운 상대를 태그하게 만듦 = 공유** | "변호사한테 물어보자" → 애인 태그 → 둘 다 들어와서 또 댓글 |
| ④ | **판정자의 권위가 주제 바로 옆** | 이혼 전문 변호사 = 연애 싸움의 끝을 아는 사람 (살짝 웃김 + 신뢰) |
| ⑤ | **영상은 초대장, 콘텐츠는 댓글** | 9초로 끝 → 반복 재생. 사람들은 남의 싸움 읽으러 댓글창에 머묾. 사연은 다음 편 소재로 쌓임 |

→ 핵심은 '판정'이라는 단어가 아니라 **"결론 안 난 둘 사이의 다툼 + 상대를 태그할 이유 + 그 다툼을 끝낼 자격 있는 사람"**.

## 2. 착한언니 버전으로 다시 기획 (원리 → 대표님 현장)
단어를 바꾸는 게 아니라, 위 다섯 개가 **대표님 현장에서 실제로 존재하는 곳**을 찾음.

| 원리 | 착한언니 현장에서 실제로 있는 것 |
|---|---|
| ① 결론 안 난 다툼 | **집 고르다 싸우는 부부·커플.** 역세권 작은 집 vs 멀어도 넓은 집, 친정 근처 vs 회사 근처, 전세 vs 영끌 매매, 신축 vs 구축. 집 보러 온 부부가 사무실에서 실제로 싸움 |
| ② 객관적 확인 욕구 | 집 싸움은 감정 같지만 **숫자로 결론이 나는 싸움** (출퇴근 시간, 이자, 시세, 되팔 때 수요) |
| ③ 태그할 상대 | 배우자·애인. "언니한테 물어보자" → 태그 |
| ④ 주제 옆의 권위 | 서울에서 부동산 12년, **집 앞에서 싸우는 부부를 매주 보는 사람** |
| ⑤ 초대장 + 댓글 | 0편은 초대장 10초, 1편부터 실제 댓글로 판정 시리즈 |

왜 대표님한테 맞나
- 대표님 타깃(첫 집·신혼)이 그대로 댓글로 들어옴 → 팔로우 이유가 생김 ("우리 집 고를 때 언니한테 물어봐야지")
- 판정에 **숫자를 쓰는 건 중개사만 할 수 있음** — 변호사 판정과 겹치지 않는 대표님 몫
- 촬영 부담 최소 (혼자, 10초 / 판정 편 30~40초)
- 언니집 AI 계산과 자연스럽게 연결 가능 (판정 편에서 계산 화면)

## 3. 0편 — 초대장 (10초)

**장소:** 사무실 앞 또는 매물 전단 붙은 유리문 앞, 셀카 구도로 걸어오며
**상단 고정 자막:** 집 때문에 싸운 부부·커플 댓글 남겨봐 / 누가 맞는지 숫자로 판정해 줌

**대사**
> "집 때문에 싸우셨어요? 댓글 남겨 주세요.
> 서울에서 부동산 12년, 집 보러 와서 싸우는 부부 매주 봐요.
> 누가 맞는지, 숫자로 판정해 드릴게요."

- CTA·DM 없음 (레퍼런스처럼 순수 초대장. 자료 DM은 판정 편부터)
- 캡션: "역세권 vs 넓은 집 / 친정 근처 vs 회사 근처 / 전세 vs 매매… 싸운 이유 댓글로 남겨 주세요. 배우자 태그 환영 😂 (사연은 판정 영상에 익명으로 소개될 수 있어요)"

## 4. 1편~ — 판정 편 (30~40초) 틀
**실제 댓글만 사용** (지어내지 않음 · 아이디 가림 · 캡션에 소개 고지)

1. (0~3초) 댓글 캡처 화면 + 대표님 읽기: 실제 댓글 한 줄 그대로
2. (3~25초) 숫자 2~3개로만 비교 — 그 댓글에 나온 실제 조건으로 계산
   - 예시 항목: 출퇴근 왕복 차이 × 한 달, 대출 이자 차이 월액, 같은 단지 실거래로 본 되팔 때 수요
3. (25~32초) 판정 한 줄: "이 집은 ○○ 쪽이에요."
4. (32~38초) 뒤집히는 조건 한 줄: "단, 2년 안에 아이 계획 있으면 뒤집혀요." → 또 댓글 토론
- 숫자는 전부 공공데이터 실거래·실제 금리로 ✍️ 확인 후 사용
- 단정 금지 영역(세금·대출 한도)은 "은행·세무사 확인" 한 줄

## 5. 리스크·확인
- 0편 올리고 댓글이 안 모이면 판정 편을 못 만듦 → 대표님 실제 상담 사례(익명·각색 고지)로 1편 준비해 두기
- 특정 단지 비하·특정 선택 조롱 X — 판정은 "이 조건이면"까지만
