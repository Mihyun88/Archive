# 숏드라마 v8 · "나는 안 당해"가 무너지는 50초 (약 55초)
대표님 방향: 보는 사람이 "나는 안 당할 것 같은데… 저 상황이면 나도 하겠다"를 느끼게. 주인공은 똑똑하고 다 확인함 → 확인할 때마다 그럴듯한 답이 돌아와 한 단계씩 쌓임 → 결국 계약
v8 (11/23 대표님): 속마음 자막 X → 주인공이 직접 말로 확인 ("~죠?") → 김팀장 "당연하죠 / 그럼요"가 반복 → 마지막에 처음으로 "당연하죠"가 안 돌아옴
장치: 확인 질문 → 그럴듯한 답 → 안심 반복 · 작은 약속부터(가계약금 50만)
인물: 김팀장(친절하고 말 잘함, 악역 티 X) / 20대 초반 직장인(꼼꼼함) · 장소: 신축 빌라 → 부동산 사무실
상단 고정: 다 확인했는데, 왜 당했을까

① 미끼 (신축 빌라)
- 김팀장 (현관 열며 슬리퍼 내려놓고) "역 5분, 신축 풀옵션. 이사비 300 지원되고, 복비는 집주인이 내요."

② 확인 1 — 시세
- 직장인 (둘러보다 휴대폰 보며) "사진보다 훨씬 좋네요. 근데 근처 빌라 매매가 2억 정도던데, 여기 전세 2억 2천이면 좀 높지 않아요?"
- 김팀장 (차분하게) "신축은 실거래가 아직 없어서 그렇게 보여요. 은행에서 전세대출 승인 나는 집이에요."
- 직장인 "은행이 대출해 주면 괜찮은 거죠?"
- 김팀장 "그럼요. 은행이 다 보고 내주는 거니까요."

③ 확인 2 — 등기부
- 직장인 "등기부도 확인해 주시는 거죠?"
- 김팀장 (바로 휴대폰 화면 보여주며) "당연하죠. 여기요, 근저당 하나도 없어요. 안심하셔도 돼요."
- (화면: 을구 기록사항 없음)

④ 확인 3 — 집주인
- 김팀장 (바로 이어서, 가볍게) "아, 잔금 전에 주인이 한 번 바뀌어요~ 신축은 다 그래요. 새 집주인 신분증 사본도 드릴게요."
- 직장인 "아 네네."

⑤ 압박 — 작은 약속부터
- 김팀장 (휴대폰 진동 보며) "아, 오후에 보기로 한 신혼부부가 먼저 하겠다고 연락 왔네요… 가계약금 50만 원만 걸어 두실래요?"
- 직장인 (잠깐 망설이다) "50만 원이면… 마음 바뀌면 돌려주시는 거죠?"
- 김팀장 "그럼요."
- 송금 '띵'

⑥ 마지막 확인 (부동산 사무실)
- (벽에 걸린 중개사무소 등록증 클로즈업 · 대표 이름)
- 직장인 (등록증 보며) "등록증도 걸려 있네요."
- 김팀장 "대표님 외근이라 도장은 제가 찍어 드릴게요."
- 직장인 "아 네네. 보증보험도 되는 거죠?"
- 김팀장 "그럼요, 당연하죠."
- 직장인 (계약서에 서명) · 대출 실행 문자 '띵'

⑦ 2년 뒤 (자막: 만기 D-7)
- 직장인 (전화) "만기가 다음 주라서요. 보증금 2억 2천, 돌려주시는 거죠?"
- 새 집주인 (귀찮은 목소리) "저 돈 없어요. 명의만 빌려준 거라." (뚝)
- 직장인 (보증보험 '가입 불가' 문자 화면을 보며) "…나 진짜 다 확인했는데."

⑧ 정지 화면 (놓친 3가지)
- ① 은행 대출 승인 ≠ 시세 확인 → 주변 실거래로 직접 비교
- ② 보증보험 '된다'는 말 ≠ 가입 승인 → 계약하고 잔금 전에 HUG 전세보증 사전심사로 확인
- ③ 등록증 걸린 사무실 ≠ 도장 찍는 사람 → 서명하는 사람이 등록된 공인중개사 본인인지
- 끝

연출 메모: 김팀장은 끝까지 친절함(악역 음악 X) · 속마음 자막 없음 · "~죠?" → "당연하죠/그럼요" 리듬 유지 · 각 확인 장면은 "확인 ✔" 초록 체크 → 마지막 정지 화면에서 하나씩 빨간 ❌로 뒤집힘

근거: 국토부 안심전세 사례(집값보다 비싼 보증금 · 계약 직후 집주인 변경 · 무등록 실장(팀장) · 무자본 갭투기 · 리베이트) · 쪼변 전세사기 편(신축빌라 시세 불분명 · 미끼 조건 · "보증보험은 된다더라가 아니라 직접 승인까지") · 가계약금 반환은 합의 내용에 따라 다름(대사의 "돌려드릴게요"는 실장의 말일 뿐) · "사기" 단정 X
