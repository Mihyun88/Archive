## S1 상황극 v2 · 잔금 날 몰래 대출 받은 집주인 (50초 · 틀 ① 사이다)

|---|---|---|

| 4~9 | 집주인 (커피 들고 느긋) "아~ 그거 잠깐 쓰고 금방 갚을 거예요. 형식적인 거야." | |
| 9~15 | 세입자 "그럼 잔금은 그거 말소되고 보낼게요." 집주인 "아니 오늘 이사 들어오면서 무슨 소리예요. 오늘 전입신고 하면 되잖아요, 그쪽이 먼저야." | 집주인 짜증 시작 |
| 15~22 | 세입자 (웃음) "전입은 내일 0시부터고요. 근저당은 오늘 바로 걸리죠. 제가 2등 되는 거, 알고 하신 거잖아요." | 💥 자막: 전입 = 다음 날 0시 / 근저당 = 오늘 |
| 22~27 | 집주인 (커피 내려놓으며) "…그건 법이 그런 거고. 계약했으면 돈 보내야지, 안 보내면 그쪽이 위약이에요." | 악역이 '법'을 꺼냄 |
| 27~36 | 세입자 (계약서 펼쳐 손가락으로 톡) "법이요? 좋죠. 특약 2조, '잔금 다음 날까지 담보 설정 금지, 위반 시 계약 해제.' 여기 사장님 도장이요." | 특약 줄에 형광펜 |

## N1 놓치면 손해 3 · 전세 만기 (40초)
상단: 전세 만기 앞두고 이거 모르면 2년 더 묶여요
1. 집주인은 만기 6개월~2개월 전까지 말해야 해요. 아무 말 없으면 같은 조건으로 자동 연장.
2. 세입자도 2개월 전까지 말 안 하면 자동 연장. 대신 자동 연장된 세입자는 언제든 나간다고 하면 3개월 뒤 끝나요.
3. 그래서 문자로 남기세요. "만기에 나가겠습니다 / 갱신하겠습니다" 날짜 찍힌 문자 한 줄.
근거: 주택임대차보호법 제6조(묵시적 갱신), 제6조의2(해지 통지 3개월)
