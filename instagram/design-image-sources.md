# 카드뉴스 배경 이미지 · 지도 무료 소스

## ✅ 지금 바로 쓰는 중 (키 없이 자동)
| 소스 | 용도 | 조건 |
|---|---|---|
| **OpenStreetMap 지도** | 단지 위치, 역·노선 개략도 배경 (위례선 카드 1장) | 무료. 이미지에 `© OpenStreetMap contributors` **표기 필수**. 카드 몇 장 수준의 사용은 괜찮지만, 대량 자동 다운로드는 금지돼 있어요 |
| **Nominatim (OSM 주소 검색)** | 역·지명 → 좌표 변환 | 무료, 초당 1회 이하로만 호출 |

## 🔑 무료 API 키만 받으면 바로 연결 가능 (1~2분 가입)
키를 알려주시면, 카드 주제에 맞는 사진을 제가 자동으로 검색해서 배경에 넣을 수 있어요.

| 소스 | 장점 | 라이선스 | 가입 |
|---|---|---|---|
| **Pexels** | 아파트·도시·인테리어 사진 많음 | 무료, 상업 이용 가능, 출처 표기 권장 | pexels.com/api |
| **Pixabay** | 일러스트·벡터도 있음 (아이콘형 배경) | 무료, 상업 이용 가능 | pixabay.com/api/docs |
| **Unsplash** | 감성 사진 품질 최고 | Unsplash 라이선스(무료, 상업 가능) · 데모 키는 시간당 50회 | unsplash.com/developers |

> 해외 사진 사이트에는 **한국 아파트 사진이 적어요.** "서울 아파트" 같은 장면은 아래 공공 소스나 직접 찍은 사진이 더 잘 맞아요.

## 🇰🇷 한국 장면이 필요할 때 (직접 다운로드)
| 소스 | 내용 | 조건 |
|---|---|---|
| **공공누리 1유형 이미지** (서울시·지자체·공공기관) | 서울 도심, 한강, 신도시 전경 | 출처 표시하면 상업 이용 가능. **유형(1~4)을 꼭 확인** |
| **한국관광공사 포토코리아** | 서울 야경, 도시 풍경 | 이미지마다 이용 조건이 달라요. 공공누리 1유형만 쓰기 |
| **브이월드(국토교통부)** | 항공사진, 지적도 | 키는 있지만 해외 서버에서 막혀 있어서, 사용자 크롬으로만 조회 가능 |

## ⭐ 가장 좋은 배경: 직접 찍은 현장 사진
12년차 중개사 계정의 강점은 **현장**이에요. 단지 입구, 역에서 걸어가는 길, 집 안 체크 포인트를 휴대폰으로 찍어 두세요.
- 사람 얼굴·동호수·차량 번호판은 나오지 않게
- 세로(4:5)로 찍으면 카드에 바로 써요
- 찍어 두면 제가 톤 보정·오버레이·문구 배치까지 맞출게요

## 디자인 원칙 (지금 카드에 적용한 것)
- 배경 사진·지도는 **채도를 낮추고 크림색 톤**을 덮어 글자가 묻히지 않게
- 제목 영역은 위쪽 그라데이션으로 가리고, 지도·사진은 아래쪽 2/3에만
- 출처 표기는 오른쪽 아래 작은 글씨로 고정
