## 3. 카드뉴스 = 보상형으로 (댓글 → 자료)

### 왜 바꾸나
- 캐러셀 66개 중 댓글로 자료를 준 건 **7/26 "1억 8천으로 서울 아파트" 하나뿐**인데, 혼자 **댓글 248개**(나머지 캐러셀은 대부분 0~12개)
- 지금 캐러셀은 저장·공유는 되지만 **댓글이 없어 팔로우·상담으로 이어지는 통로가 없음**
- 릴스에서 이미 검증된 흐름(리스트 댓글 6,110)을 카드뉴스에도 똑같이 적용

### 장수는 4~6장으로 (데이터 기준)
도달 2천 이상 캐러셀 61개를 장수별로 나눠 봤어요.

| 장수 | 개수 | 저장률 중앙값 |
|---|---|---|
| **1~4장** | 2 | **5.95%** (잔금일 체크리스트 7.0%, 집보기 체크리스트 4.9%) |
| 5~7장 | 25 | 0.69% |
| 8~10장 | 30 | 0.71% |
| 11장 이상 | 4 | 1.76% |

1~4장 표본은 2개뿐이라 확정할 수는 없어요. 그래도 **저장률 1, 2위가 모두 4장짜리**였어요. 반면 지금 가장 많이 쓰는 8~10장은 저장률이 가장 낮았어요. 그래서 기본 틀을 **4~6장**으로 바꿉니다.

### 구성 원칙: "본문은 충분히 주고, 확장판을 보상으로"
보상을 위해 본문을 비워두면 **저장이 줄어들어요.** 카드 안에서 완결된 정보를 주고, 댓글 보상은 **더 깊은 확장판**으로 설계합니다.

| 장 | 역할 | 내용 |
|---|---|---|
| 1 | 표지 | 손실형 제목 + 숫자 + 우측 하단 배지 `💬 댓글 '키워드' → 원본 PDF` |
| 2~4 | **무료 본문** | 한 장에 핵심을 몰아서 (표·타임라인·체크박스형) + 현장 사례 한 줄 |
| 5 | 보상 미리보기 + CTA | 자료 표지·목차를 흐리게 보여주고 `댓글에 '키워드' → DM` + 팔로우 확인 안내 |

> 내용이 많아도 6장을 넘기지 말고, 넘치는 부분은 **보상 자료로** 보내세요.

### 11/4 "잔금 30일 캘린더" 판단
- **10장은 의미가 없어요.** 캘린더는 "한눈에 보는 것"이 핵심 가치인데, 10장으로 나누면 오히려 그 가치가 사라져요.
- **2주 전(10/21) "잔금일 체크리스트 20가지"(4장, 저장률 7.0%)와 겹쳐요.** 그대로 반복하면 피로도가 생기니 **"2편: 잔금 전 30일"** 로 각도를 바꾸고, 표지에서 10/21 게시물을 언급해 연결하세요.
- **추천 구성 (4장)**
  1. 표지: "잔금 30일 전부터, 이 순서 틀리면 대출 안 나와요" + `💬 잔금`
  2. **한 장 캘린더**: D-30 / D-14 / D-7 / D-1 / D-day 타임라인 (저장용 핵심)
  3. **가장 많이 놓치는 3가지**: 현장 사례 한 줄씩
  4. 보상 미리보기 + CTA: 날짜를 넣으면 일정이 계산되는 캘린더 PDF + 잔금일 체크리스트 20

## 참고: PDF 분석에서 반영한 것 / 거른 것

**반영함**
- 첫 3초 숫자 훅, 15초 중간 예고, 40~50초 길이, 주제 하나만 깊게
- 서류·실거래가를 화면에 직접 보여주기, 자료 품질 강조 멘트

**데이터와 달라 수정함**
- "월·수·금 오전 10시 업로드" → 실제 데이터상 **오전 시간대 도달이 가장 낮음**, 화·목·토 밤이 유리
- 자취·전세·세입자 훅 위주 제안 → 실제 팔로워는 **35~44세 매수자**가 중심, 해당 주제 릴스는 하위권

**참고만 함**
- "폭발한 영상 3개"는 PDF 스스로 밝힌 **가상 사례**
- 3개월 10만 · 월 1,000만 원 같은 성장·수익 예측은 근거가 제시되지 않음
