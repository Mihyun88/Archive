```
0~3초   숫자 + 충격 사실로 시작 (인사·"여러분" 금지)
        예) "2016년 6억, 지금 15억. 같은 단지입니다."

15초    ★ 중간 예고: "이 리스트 받는 법은 영상 끝에 알려드릴게요"
15~40초 근거 — 실거래가 화면, 서류 실물, 현장 사진을 화면에 띄우기
40~50초 행동 유도: "댓글에 '키워드' 남기시면 전체 자료 보내드려요"
```

- 길이 **40~50초** 고정, 한 영상에 **주제 하나** (19초에 10가지 몰아넣지 않기)

- 캡션 마지막 줄 고정: `📩 상담은 프로필 링크 → 카톡 채널`

## 3. 카드뉴스 = 보상형으로 (댓글 → 자료)

### 왜 바꾸나
- 캐러셀 66개 중 댓글로 자료를 준 건 **7/26 "1억 8천으로 서울 아파트" 하나뿐**인데, 혼자 **댓글 248개**(나머지 캐러셀은 대부분 0~12개)
- 지금 캐러셀은 저장·공유는 되지만 **댓글이 없어 팔로우·상담으로 이어지는 통로가 없음**
- 릴스에서 이미 검증된 흐름(리스트 댓글 6,110)을 카드뉴스에도 똑같이 적용

### 구성 원칙: "본문은 충분히 주고, 확장판을 보상으로"
보상을 위해 본문을 비워두면 **저장이 줄어들어요.** 카드 안에서 70%는 완결된 정보를 주고, 댓글 보상은 **더 깊은 확장판**으로 설계합니다.

| 장 | 역할 | 내용 |
|---|---|---|
| 1 | 표지 | 손실형 제목 + 숫자 + 우측 하단 배지 `💬 댓글 '키워드' → 원본 PDF` |
| 2 | 대상 | "이런 분이라면 꼭 보세요" (잔금 앞둔 분 / 첫 집 계약하신 분) |
| 3~7 | **무료 본문** | 체크리스트 핵심 5개 — 1항목 1장, 현장 사례 한 줄 |
| 8 | 한 장 요약 | 저장 유도용 요약표 |
| 9 | **보상 미리보기** | 자료 표지·목차를 흐리게(블러) 보여주기 + "전체 20항목 · 날짜별 할 일 · 체크박스 PDF" |
| 10 | CTA | `댓글에 '잔금' 남기시면 DM으로 보내드려요` + 팔로우 확인 안내 |

**캡션 구조**
```
1줄: 표지 제목 반복 (손실형)
2~4줄: 본문 요약 3줄
5줄: 📩 댓글에 '키워드' 남기시면 [보상 자료명] DM으로 보내드려요
6줄: (팔로워분들께만 발송돼요)
마지막: 📞 상담은 프로필 링크 → 카톡 채널
```

**고정 댓글**: 올리자마자 본인이 `👇 '키워드' 댓글 남겨주세요! 순서대로 DM 드려요` 고정

### DM 흐름 (노션 템플릿 기존 흐름 그대로)
```
댓글 '키워드' → 1차 DM: 팔로우 확인 → [팔로우했어요] 버튼
            → 2차 DM: [자료 받기] 버튼 → 카카오 소식 랜딩 → 노션 자료
            → 자료 하단: 카톡 상담 CTA
```

### 주의할 점
- **보상은 반드시 실제로 줄 수 있는 자료만.** 표지에 약속한 내용과 DM 자료가 다르면 신뢰가 깨져요
- 자동 DM 도구는 인스타 정책상 **댓글 단 사람에게 1회 응답**만 허용되는 경우가 많아요. 버튼 흐름으로 한 번에 끝내기
- 같은 키워드를 여러 게시물에 쓰면(예: `청약`) 자동 응답 설정을 **게시물별로** 걸어야 해요
- 성과 측정: 카드뉴스 **댓글 수 / 도달**을 새 지표로 추가 (목표 1%+, 7/26 1억8천 카드 = 1.2%)

## 참고: PDF 분석에서 반영한 것 / 거른 것

**반영함**
- 첫 3초 숫자 훅, 15초 중간 예고, 40~50초 길이, 주제 하나만 깊게
- 서류·실거래가를 화면에 직접 보여주기, 자료 품질 강조 멘트

**데이터와 달라 수정함**
- "월·수·금 오전 10시 업로드" → 실제 데이터상 **오전 시간대 도달이 가장 낮음**, 화·목·토 밤이 유리
- 자취·전세·세입자 훅 위주 제안 → 실제 팔로워는 **35~44세 매수자**가 중심, 해당 주제 릴스는 하위권

**참고만 함**
- "폭발한 영상 3개"는 PDF 스스로 밝힌 **가상 사례**
- 3개월 10만 · 월 1,000만 원 같은 성장·수익 예측은 근거가 제시되지 않음
